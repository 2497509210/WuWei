# 手机快捷录入与位置入口

用户要求继续推进既定计划。本轮做手机桌面入口、拍照登记、最近位置和容器/隔层二维码；楼层管理继续暂缓，独立箱子搬家/空间规划产品不新增。本轮按既有授权测试、备份并部署。

## 使用方式

1. 找物页点击「拍照登记」，通过「拍摄或选择照片」调用浏览器支持的原生相机或文件选择，填写物品名称、选择隔层，再「保存物品」。照片可选；失败保留名称、照片预览和所选位置，原样重试复用操作编号，修改内容后使用新编号。
2. 原批量「登记物品」继续可用。从隔层进入时优先回填该隔层，否则使用本浏览器此用户、此家庭最近成功登记的位置；每次打开都向服务器重新解析名称与归属。失效位置清空，不回退到其他隔层。用户或家庭切换会清除当前草稿，防止串用。
3. 空间页打开容器隔层弹窗，点击「位置标签」。选择「整个容器」或「所选隔层」，默认当前入口；已知部署主机允许选择 Tailnet 内网或公网。连接 Tailscale 的手机可用内网入口，其他手机用公网入口。可复制链接，或「下载标签（SVG）」后打印；名称标注取生成时的值，改名后可重新下载。
4. 扫码打开 `/location/{containerId}?compartment={id}`，部署时加 `/wuwei` 前缀。登录或通过邀请码加入后仍回到原目标，显示当前房间和隔层，并可查看物品或登记。容器换房间后旧链接仍可解析；已删除或无权位置显示错误。
5. 找物页点击「添加到手机桌面」，按浏览器可用安装入口或 Safari / Android 菜单说明操作。桌面入口保留添加时的访问地址并打开家庭找物。需要在线使用；本版无 Service Worker、无离线个人数据缓存，不提供离线功能。

## 交互

- 家庭找物页提供“拍照登记”，使用 `capture=environment` 请求原生相机或文件选择，实际选择器由设备和浏览器决定。照片可选，填写名称及一个位置后提交；带照片时照片和物品由同一后端事务登记，失败可重试，不制造缺少所选照片的半条记录。拍照非 AI 识别，不替用户推断物品名称。
- 原有批量登记保留；在隔层内登记优先选择该隔层，其次恢复本浏览器此用户/家庭最近一次成功使用的位置。持久化只存隔层ID，真实名称/归属每次由服务端重新核验；无效或已删除位置清空，不能继续把物品登记到过期ID。用户/家庭切换不能串用记录。
- 容器隔层弹窗提供“位置标签”。可生成整个容器或已选隔层二维码与可复制链接；选择当前入口、Tailnet内网或公网，内外网选择仅在已知部署主机显示，默认当前入口。二维码不含cookie、邀请码或访问令牌，不提供免登录读取。
- 稳定地址`/location/{containerId}?compartment={id}`。服务端验证户归属，容器换房间后链接仍可解析当前房间；已删除/无权位置显示错误，不退回其他位置。页面显示隔层图，可查看隔层物品或登记到此隔层。
- 物品列表使用URL查询`/find?compartment={id}&register=1`启动批量登记，`capture=1`启动拍照登记；消费启动参数后replace清除动作参数，保留筛选，刷新不重复弹窗。登录/注册bootstrap保持深链接，查看全部清query及旧history state。
- 提供manifest和192/512图标、apple-touch-icon，start_url=find、display=standalone。添加桌面提示优先浏览器安装事件，缺省显示对应浏览器菜单操作说明；安装由用户点击，不自动修改设备设置。无Service Worker、无离线个人数据缓存，离线显示网络错误并保留当前表单输入。

## API

- `GET /api/containers/{id}` -> `{room:RoomSummary,container:Container}`，登录且本家庭。
- `GET /api/locations/compartments/{id}` -> `{location:{room_id,container_id,compartment_id,path:string[]}}`，登录且本家庭。
- `POST /api/items/quick` multipart字段`name,compartment_id,operation_id,image?` ->201 `{item}`（幂等重试200）。名称沿用1..120 trim，photo沿用8MiB/20Mpx重编码校验；operation_id按家庭绑定请求指纹包含照片内容hash，不同内容同ID409。图片解码后事务内再验证会话/位置，物品create及photo历史同事务；失败删除新文件。已有同operation结果返回同item，不追加history/照片。
- 增量迁移 `006_quick_registration` 新建快捷登记幂等操作表，保留批量登记表逻辑。
- `/manifest.webmanifest`和`/app-icons/*`提供明确Content-Type，不落入SPA HTML fallback；兼容空前缀与`/wuwei`。

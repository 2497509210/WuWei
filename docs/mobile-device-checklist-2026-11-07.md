# 手机兼容验收边界

自动化使用Playwright锁定版本的Chromium与WebKit，运行同一套360／390px触摸视口流程。它验证真实浏览器引擎，不是把Chrome伪装成Safari，但仍不等于真实iPhone或Android手机。

## 自动化范围

`tests/e2e/mobile-compat.mjs`覆盖真实登录、筛选与分页刷新、CSV生成和下载、合成大图处理、上传失败保留及重试、原图查看和按钮缩放、草稿关闭与返回、联网恢复和页面溢出。`tests/e2e/item-links.mjs`覆盖物品链接复制降级、直接打开／刷新、登录／加入／过期后返回、跨家庭拒绝、归档和错误页。

通过`WUWEI_TEST_BROWSER=chromium|webkit`明确指定引擎。Windows本机WebKit二进制位于忽略目录`tests/.browsers`，需设置`PLAYWRIGHT_BROWSERS_PATH`；CI按默认Playwright缓存安装。结果按引擎分别保存，禁止无法启动时自动换Chrome并声称WebKit通过。

Windows WebKit 27.2测试运行时的Blob下载会报`Load request cancelled`；独立空白页原生Blob链接同样复现。本机仅对此明确标记未验证文件落盘，另核对实际CSV响应正文，不能算下载通过。Linux CI保持严格要求，必须成功保存文件再核对内容。此差异不代表真实Safari下载一定失败。

2026-11-08发布验收：Linux CI `42441283193` 中Chromium和WebKit的360／390px CSV实际下载及正文检查均通过；双引擎物品链接与手机流程共94项通过。以下真机项目仍未执行，不因CI成功而勾选。
